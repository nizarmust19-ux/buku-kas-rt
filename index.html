📚 Panduan Penggunaan Kas RT

1. Menu Utama

  • Laporan: Melihat saldo kas, total masuk/keluar, dan menyaring transaksi (default 30 hari terakhir).
  • Input Kas: Khusus pengurus untuk mencatat transaksi baru (memerlukan sandi).
  • Pengurus: Daftar nama dan kontak WhatsApp pengurus RT.
  • Saran / Pojok Warga: Tempat mengirim masukan atau pesan untuk RT.

2. Cara Input Transaksi

  1. Klik ikon Input Kas.
  2. Masukkan sandi pengurus.
  3. Isi tanggal, uraian, nominal masuk/keluar, lalu simpan.

3. Cetak & Rekap

  • Gunakan tombol Unduh PDF untuk menyimpan arsip laporan.
  • Gunakan tombol Rekap WA untuk membagikan laporan ke grup warga.
